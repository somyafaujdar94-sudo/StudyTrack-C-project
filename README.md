
# STUDYTRACK – Smart Study Time Analyzer

## About
STUDYTRACK is a beginner-friendly C programming mini project for BCA Data Science Semester 1.

It records study hours for three subjects and generates a simple study report.

## Features
- Enter three subject names.
- Enter study hours.
- Calculate total study hours.
- Calculate average study hours.
- Find the most studied subject.
- Display a performance message.

## Technologies Used
- C Programming
- GCC Compiler

## Concepts Used
- Variables
- Arrays
- For Loops
- If-Else Statements
- Arithmetic Operators
- Input and Output Functions

## How to Run
1. Download studytrack.c.
2. Compile using GCC:
   gcc studytrack.c -o studytrack
3. Run the program.
